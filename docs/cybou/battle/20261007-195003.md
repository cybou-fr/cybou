## Persistence failure investigation

Both prepared client DB copies decoded their state and matched its stored hash,
but lacked the required `cybou/network-id` record after reopening. The second
original DB was missing `CURRENT`; its 2,627,669-byte manifest still had 5,593
valid logical records and next file number 14,590. Opening a copy without CURRENT
allowed LevelDB's create-if-missing to recreate the DB and discard old tables.
The first prepared Identity vault was also absent, so the clean restore could
not proceed. The cause of the original file disappearance is unresolved.

The implementation now refuses a missing CURRENT when database artifacts remain,
preserving evidence before LevelDB recovery. No failing DB was repaired, reset or
accepted as a measurement reference. Logs and diagnostic copies are retained under
`artifacts/ux-r3-20261007/` and the original run directory.
