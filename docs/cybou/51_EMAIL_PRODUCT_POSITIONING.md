# 51 — CYBOU Email product positioning

## Core statement

```text
CYBOU Email
=
European sovereign E2E encrypted email
+
consensus registration
+
cryptographic proof of origin/integrity
```

Designed in France.

## Differentiation

CYBOU Email is not positioned as:

- another realtime messenger;
- a Gmail clone;
- SMTP hosting;
- a cryptocurrency chat application.

Its distinguishing model is:

```text
write
-> encrypt
-> sign
-> register through BFT consensus
-> finalized cryptographic mail record
```

## User value

A native mail can carry verifiable protocol evidence of:

- sender signature;
- cryptographic commitment;
- finalized registration;
- chain position/time evidence;
- integrity.

Use "cryptographic registration" or "notarial-like proof" carefully.

Do not claim legal notarization without legal qualification.

## First release

```text
text-only
one-to-one
native .cybou
E2E encrypted
consensus registered
no attachments
no SMTP
```

Attachments and large mail arrive only with CYBOU Object Storage.

## Long-term

```text
Blockchain / state
    -> proof, ordering, commitment

CYBOU Store
    -> encrypted bytes and attachments

Local client
    -> decrypted user mailbox
```
