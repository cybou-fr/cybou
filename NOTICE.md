CYBOU source file carries `SPDX-License-Identifier: Apache-2.0`.

CYBOU began as a fork of Bitcoin Core. The Bitcoin-derived components were
removed or rewritten by the CYBOU author, so no Bitcoin Core source file with
an MIT header remains in the tree. The original MIT license text is kept in
`COPYING` as a record of that ancestry, which stays visible in Git history.

Third-party components retain their own copyright and license notices (for
example `src/leveldb/LICENSE` and `src/crc32c/LICENSE`). The BIP-39 English
word list (`src/cybou/bip39_english.inc`) comes from the bitcoin/bips
repository; its attribution is retained.

The exact imported commit still requires provenance reconciliation as described
in `docs/cybou/UPSTREAM_BASELINE.md`.
