# CYBOU desktop localization

The native CYBOU desktop currently ships without translation catalogs. Its UI
uses English source strings, and the build does not include the inherited
Bitcoin Qt catalogs or translation tooling.

When CYBOU localization is introduced, define its source language, supported
locales, review workflow, and catalog packaging together. Until then, update
the source strings directly and do not add `.ts`, `.qm`, or Transifex files.
